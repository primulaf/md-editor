# v1.6.2

发布日期：2026-08-03

v1.6.2 改善内嵌图片较多时的编辑体验，扩大滚动操作区域，修复双击关联文件产生的临时存储残留，并将扩展发行方式收敛为单一完整包。

## 图片编辑

- 粘贴或拖入的 DataURL 图片在编辑区显示为短引用，避免长编码占满文档并干扰目录跳转。
- 预览、保存、另存为、复制和 HTML 导出时自动还原完整图片数据，保存后的 Markdown 保持可移植。
- 相同图片自动复用同一份资源数据，减少当前标签页的内存和会话存储占用。
- 兼容打开旧文档中的完整 DataURL，并在输入后自动收起，同时保持光标位置。
- 刷新页面时恢复当前标签页的图片资源；数据缺失时阻止不完整保存并显示明确提示。

## 滚动与分栏

- 加宽编辑区和预览区滚动条，增加悬停反馈，降低滚动条与分栏手柄的误操作概率。
- 调整分栏手柄命中区域和比例计算，使其不再覆盖编辑区滚动条。
- 分栏手柄支持键盘调节，并补充焦点样式和无障碍属性。
- 目录点击改为确定性定位，避免平滑滚动超时后被双栏同步打断；滚动高亮和目录自动跟随保持正常。

## 文件关联稳定性

- 关联文件内容和文件名改为单个带时间戳的临时信封，避免两份状态不一致。
- 文件发送失败或扩展页跳转失败时立即清理临时数据。
- 使用 Manifest V3 的定时任务进行兜底回收，并在编辑器启动时清除超过 30 分钟的待处理项。
- 自动移除旧版本遗留的 `file:*` 和 `name:*` 数据，多标签页并发打开时保护当前任务。

## 发行方式

- Release 只提供 `md-editor-1.6.2.zip`，其中包含完整 Mermaid 离线运行库。
- 不再发布 Full、Lite 和独立 Mermaid Dependency 包，降低选包与升级复杂度。
- Mermaid 能力和版本探测仍保留；运行库缺失、损坏或不兼容时回退显示源码并提供重新安装说明。
- `SHA256SUMS.txt` 只记录唯一 ZIP 的 SHA-256。

从旧版 Full 或 Lite 包升级时，请将 `md-editor-1.6.2.zip` 解压到新的空文件夹，再到 `chrome://extensions` 重新选择或加载该目录，不要直接覆盖旧扩展目录。

## 验证

- 图片资源模块 7 项测试通过，覆盖压缩、展开、去重、快照、缺失数据和光标映射。
- 文件关联临时存储模块 4 项测试通过，覆盖空文件、键名校验、过期清理和并发保护。
- Mermaid 能力探测 4 项测试通过。
- 项目结构、扩展权限、脚本加载顺序、发行包文件清单、Mermaid 103 个分块和 SHA-256 校验通过。
- 浏览器回归覆盖图片短引用与预览、目录点击和滚动跟随、分栏键盘调节以及窄屏布局。
