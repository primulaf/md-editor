# v1.7.0

版本日期：2026-08-03
状态：已发布

v1.7.0 扩展 Markdown 阅读能力，加入完整深色模式与最近文件入口，并为 Mermaid 图表提供缩放和单图下载工具。

## Markdown 与阅读

- 支持 GitHub 风格只读任务列表，复选状态来自 Markdown 源码。
- 支持脚注引用、脚注定义和返回正文链接；预览与 HTML 导出行为一致。
- 首次打开的示例文档同步展示任务列表、脚注、主题与图表工具。

## 明暗主题

- 侧栏新增紧凑的明暗主题按钮，默认保持浅色，选择会在刷新后保留。
- 多个扩展标签页同步主题偏好；首屏在样式加载前恢复主题，避免明显闪烁。
- 深色模式覆盖侧栏、编辑区、预览区、目录、表格、滚动条、状态与对话框。
- 代码高亮与 Mermaid 随主题切换；HTML 导出继续使用固定浅色样式。

## 最近文件

- 侧栏按需显示“最近”菜单，最多保存 12 个工具内打开或双击关联的 Markdown 文件；浮层越过侧栏边界显示，不再被预览区遮挡。
- 文件按最近使用排序；句柄记录按真实文件身份去重，关联记录按完整本地地址去重，均不保存文档内容。
- 点击记录时重新申请本地文件权限；取得写权限后可继续直接保存。
- 双击关联记录会从原 `file://` 地址重新读取磁盘最新内容，并明确标注“保存需授权”。
- 文件被移动、删除或读取权限被拒后自动移除失效条目。
- 最近文件存储不可用时隐藏入口，不影响常规打开流程。

## 侧栏与文档摘要

- 文档入口、编辑操作和显示设置重新分组；“新建文档”“导出 HTML”收进按需展开的更多菜单。
- 字号由循环切换改为小 / 中 / 大分段选择，当前档位更直观，刷新后继续保持。
- 标题数并入目录标题，四格统计卡片改为底部单行摘要，把主要高度留给目录。
- 字数与预计阅读时间排除图片编码、代码块、Mermaid 源码、行内代码和链接地址；编辑模式额外显示行数。
- 统计仅在文档内容变化时更新，不再周期性扫描未变化内容。

## Mermaid 图表工具

- 成功渲染的图表提供 50%–300% 缩放与一键复位，缩放会更新真实滚动范围。
- 单图可下载净化后的 SVG 或 2 倍 PNG，文件名包含当前文档名和图表序号。
- PNG 最大边长限制为 8192px、最大面积为 3200 万像素，超限时自动降低倍率。
- 工具栏和预览缩放状态不会进入 HTML 导出，导出仍保留原始净化 SVG。
