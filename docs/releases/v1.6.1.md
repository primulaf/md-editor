# v1.6.1

发布日期：2026-07-29

v1.6.1 改善默认阅读字号、首次打开内容和 Mermaid 图表浏览体验，并修复超宽图表左右内容无法完整查看的问题。

## 字号

- 字号由五档收敛为小、中、大三档，删除原先偏小的两档。
- 新小号沿用原大号尺寸，新中号沿用原特大号尺寸，新大号沿用原超大号尺寸。
- 编辑区与预览区三档字号分别为 17px、19px、21px，界面字号同步调整为 15px、16px、17px。
- 旧版字号设置会自动迁移，升级后尽量保持原有实际显示尺寸。

## 默认欢迎文档

- 首次打开和新建文档时展示与当前功能一致的欢迎内容。
- 增加阅读模式、编辑模式、保存、另存为和 HTML 导出的行为说明。
- 展示目录导航、三档字号、多文档隔离、图片内嵌和快捷键等主要能力。
- 增加一张阅读与编辑流程图和一张文件保存时序图，完整包直接离线渲染，精简包显示源码及组件安装说明。

## Mermaid 浏览体验

- 鼠标位于图表内时，纵向滚轮继续滚动预览文档，不再形成滚动陷阱。
- 普通图表框按实际内容宽度收缩并居中，减少无意义的整行占位。
- SVG 固有宽度从 `viewBox` 保留到预览样式，避免内容框收缩时图表塌陷。
- 超宽图表从可滚动区域左侧开始排布，修复居中溢出导致左侧内容落入负坐标、无法查看的问题。
- 宽图仅在确实超过可用空间时启用横向滚动，HTML 导出使用相同布局规则。

## 验证

- 使用包含 33 张 Mermaid 图表的实际长文档完成回归测试。
- 修复前检测到 14 张超宽图存在不可访问的负向溢出，修复后全部图表横向边界正常。
- 验证超宽图可以从最左侧滚动到最右侧，普通图表继续保持居中。
- 三档字号循环、旧设置迁移、欢迎页两张示例图和图表内纵向滚轮均通过。
- `npm test`、发行包结构校验和依赖审计通过。

## 发行产物

- `md-editor-full-1.6.1.zip`：包含 Mermaid 的完整扩展。
- `md-editor-lite-1.6.1.zip`：不包含 Mermaid 运行库的精简扩展。
- `md-editor-mermaid-11.16.0.zip`：供 Lite 后续覆盖安装的组件包。
- `SHA256SUMS.txt`：三个 ZIP 的 SHA-256 校验值。

从 Release 附件选择 Full 或 Lite ZIP，解压后在 `chrome://extensions` 中开启开发者模式并选择“加载已解压的扩展程序”。已安装旧版本时，也可以解压新包后重新加载扩展。
