# v1.8.0

版本日期：2026-08-11

状态：已发布

v1.8.0 增加预览打印、代码块复用和数学公式三组能力，并升级 Mermaid 与 DOMPurify 的安全补丁版本。

## 打印 / 导出 PDF

- “更多文档操作”菜单新增“打印 / 导出 PDF”，`Ctrl/Cmd + P` 可直接调用。
- 打印前等待 Mermaid、图片和 KaTeX 字体就绪，只输出 Markdown 预览内容。
- 打印版式固定使用 GitHub 风格浅色，提供 A4 页边距、分页控制和宽内容适配。
- 修正 Mermaid 打印容器因内边距超出纸张内容区而导致的右侧截断。
- 首次打印会提示选择 Chrome 自带的“另存为 PDF”，以保留可搜索、可复制的文字；Windows“Microsoft Print to PDF”可能将文字转换为不可选择的轮廓。
- Chrome 打印窗口负责最终保存位置和纸张设置；扩展不申请额外打印权限。

## 代码块工具

- 普通代码块增加常驻的语言标签、“复制”和“下载”操作，不遮挡代码内容。
- Python、JavaScript、TypeScript、JSON、Shell、PowerShell、SQL、HTML、CSS、YAML 等语言下载为对应扩展名；未知语言回退 `.txt`。
- 文件名采用 `<文档名>-code-<序号>.<扩展名>`，下载内容保持为源码文本。
- Mermaid 图表沿用独立工具栏；代码操作控件不会进入 HTML 或 PDF 输出。

## 数学公式

- 使用 KaTeX 0.18.4 与 markdown-it-texmath 1.0.0 离线渲染 `$...$` 行内公式和 `$$...$$` 块级公式。
- 输出同时包含视觉 HTML 与 MathML；代码中的美元符号、转义美元和常见金额文本保持原样。
- KaTeX 使用 `trust: false`、有限宏展开和尺寸上限；错误公式不会中断整篇文档。
- HTML 导出仅在文档含公式时内嵌 KaTeX CSS 和 20 个 WOFF2 字体，断网后仍可独立显示。
- 文档字数与预计阅读时间排除公式源码。

## 安全与工程

- Mermaid 从 11.16.0 升至 11.16.1，DOMPurify 锁定至 3.4.13，修复依赖审计发现的公开安全问题。
- vendor、项目校验和发行包校验覆盖 KaTeX 脚本、CSS、字体、版本清单以及新增模块。
- 新增语言映射、代码文件名、公式边界、安全配置、字体内嵌与统计口径测试。
