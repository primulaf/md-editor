# v1.6.0

发布日期：2026-07-29

v1.6.0 增加完整 Mermaid 离线渲染，并将图表运行库设计为可选组件。同一份扩展源码现在可以生成完整版、精简版和独立 Mermaid 依赖包，后续开发不再需要维护两条功能代码线。

## Mermaid 图表

- 将语言标记为 `mermaid` 的代码围栏渲染为 SVG。
- 支持 Mermaid 11.16.0 内置的稳定及实验性图表类型。
- 支持流程图、时序图、类图、状态图、ER 图、甘特图、饼图和思维导图等常见类型。
- 单篇文档最多渲染 50 个图表，单图最多 50000 个字符和 500 条边。
- 图表字体跟随应用五档字号变化，宽图在预览容器内横向滚动。
- HTML 导出直接内联 SVG，不依赖 Mermaid 运行库。

## 可选组件

- Full 包包含 Mermaid，打开文档后自动渲染图表。
- Lite 包不包含 Mermaid 运行库，图表位置稳定显示源码。
- Lite 可以覆盖安装独立 Dependency 包，重新加载扩展后自动获得图表能力。
- 缺少依赖、版本不兼容或组件损坏时自动回退源码，不影响其他 Markdown 内容。
- 第一个 Mermaid 源码块提供本地安装说明，不增加用户开关。

## 性能与安全

- 普通 Markdown 文档不会加载 Mermaid 模块。
- Mermaid ESM 入口和图表类型分块全部包含在本地，不请求 CDN 或远程脚本。
- 图表串行渲染，并使用修订号阻止旧图覆盖新文档。
- SVG 缓存限制为 24 项或约 4 MiB。
- SVG 在写入预览区前经过 DOMPurify 二次净化。
- 远程图片、远程样式、脚本链接和非片段资源引用会被拒绝或清除。

## 发行产物

- `md-editor-full-1.6.0.zip`：包含 Mermaid 的完整扩展。
- `md-editor-lite-1.6.0.zip`：不包含 Mermaid 运行库的精简扩展。
- `md-editor-mermaid-11.16.0.zip`：供 Lite 后续覆盖安装的组件包。
- `SHA256SUMS.txt`：三个 ZIP 的 SHA-256 校验值。

三个产物由同一提交自动生成。构建校验会确认 Full 与 Lite 的公共代码完全一致，Lite 不包含 Mermaid 文件，Dependency 与 Full 的 Mermaid 文件完全一致。

## 验证

- Mermaid 能力探测的可用、缺失、不兼容和损坏场景通过。
- 8 种主流图表示例全部成功生成 SVG。
- Full 自动渲染、Lite 源码回退和 Dependency 覆盖升级通过。
- 800px 窄屏下无页面级横向溢出。
- `npm test`、发行包结构校验和依赖审计通过。

## 安装

从 Release 附件选择 Full 或 Lite ZIP，解压后在 `chrome://extensions` 中开启开发者模式并选择“加载已解压的扩展程序”。直接打开本地 Markdown 文件前，请在扩展详情中开启“允许访问文件网址”。

Lite 后续需要 Mermaid 时，将 Dependency ZIP 直接解压到扩展根目录并允许合并目录，然后在 `chrome://extensions` 中重新加载扩展。
