# v1.8.0 实施计划

状态：已完成并验收

## 1. 依赖与模块边界

- 锁定 KaTeX 与 Markdown-it 数学插件版本，测量 JS、CSS、字体和最终 ZIP 增量。
- 扩展 vendor 脚本，自动同步 KaTeX 浏览器文件、字体和数学插件，禁止手工修改第三方文件。
- 新增代码块工具与数学导出辅助模块，将语言映射、文件命名、DOM 增强和字体内嵌逻辑从 `app.js` 分离。
- 更新项目校验、发行包清单和测试脚本，强制依赖版本及必要文件一致。

## 2. 数学公式

- 在 Markdown-it 实例中注册数学插件并配置 KaTeX 安全参数。
- 扩展 DOMPurify 的 HTML / SVG / MathML 净化配置，验证常用公式结构不会被破坏。
- 补充预览主题、块级溢出、错误公式和无障碍文本样式。
- HTML 导出仅在存在公式时内联 KaTeX CSS 与所需 WOFF2 字体。
- 调整文档统计，排除行内和块级数学源码。

## 3. 代码块工具

- 在普通 fence 输出中保留语言元数据，渲染后统一增强代码块。
- 使用预览区事件委托实现复制、下载和反馈，避免每次渲染累积监听器。
- 建立语言别名、扩展名、MIME 和展示名称映射；未知语言回退 `.txt`。
- HTML / PDF 克隆阶段移除工具栏和包装层，保留代码内容。
- 增加纯函数测试和 Markdown 集成验证。

## 4. 打印 / 导出 PDF

- 在更多菜单增加入口，并拦截 `Ctrl/Cmd + P` 打印预览。
- 复用当前导出模板，在独立隐藏打印文档中装载净化后的预览。
- 等待 Mermaid、图片和字体就绪后调用打印；完成或取消后清理临时文档。
- 增加 A4 打印规则、分页控制和宽内容适配，固定使用浅色样式。

## 5. 文档、版本与交付

- 更新默认示例、README、AGENTS 项目结构和 v1.8.0 发行说明。
- 将 `package.json` 与 `manifest.json` 升至 1.8.0。
- 运行完整测试、打包和结构校验，记录 ZIP 大小与 SHA-256。
- 在 Chrome 中手动回归打印窗口、代码块操作、公式、主题、Mermaid 和 HTML 离线显示。
- 本阶段先生成验收包，待用户验收后再提交、推送并发布正式版本。

- 已完成 PDF 打印、代码块工具和 KaTeX 公式三组能力，并更新默认示例与项目文档。
- Mermaid 升至 11.16.1，DOMPurify 升至 3.4.13；`npm audit` 为 0 个已知漏洞。
- 自动化测试、桌面 / 窄屏 / 深色界面回归和发行包结构校验通过。
- `md-editor-1.8.0.zip` 为 1,598,191 字节，低于 3 MB 门槛。
- 手动验收覆盖 Chrome“另存为 PDF”、可选择文字、Mermaid 纸张适配、代码块操作、公式、主题和 HTML 离线显示。
