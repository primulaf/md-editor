## 实施步骤

1. 增加构建能力标记和 Mermaid 依赖版本清单。
2. 将 Mermaid 围栏改为源码优先，依赖校验通过后再进入加载与渲染状态。
3. 为缺失、不兼容和损坏状态增加源码回退及本地安装说明。
4. 保证 HTML 导出不会携带组件安装提示或空画布。
5. 建立 Full、Lite、Dependency 三产物打包脚本和 SHA-256 输出。
6. 直接检查 ZIP 内容，阻止开发文件、错误能力标记或依赖泄漏进入产物。
7. 增加能力探测单元测试，更新项目结构校验与 README。
8. 完成 Full、Lite、补装依赖三条浏览器验收路径。
