# v1.7.0 实施计划

状态：已完成并验收

## 1. Markdown 能力

- 锁定 `markdown-it-task-lists@2.1.1` 与 `markdown-it-footnote@4.0.0`，同步浏览器 UMD 文件到 `lib/`。
- 在 Markdown 实例中启用任务列表和脚注，任务复选框保持只读。
- 扩展 DOMPurify 允许属性与页面、HTML 导出样式，保证脚注锚点可跳转且导出仍完全离线。
- 增加渲染验证，覆盖任务列表、脚注引用、脚注回链与源码往返。

## 2. 主题基础设施

- 新增样式加载前运行的 `theme-init.js`，默认浅色并恢复用户选择，避免深色模式首屏闪烁。
- 侧栏工具区增加紧凑主题按钮，切换浅色和深色；通过 `storage` 事件同步多个扩展标签页。
- 使用 CSS 变量覆盖全部工具界面状态，代码高亮在 GitHub 浅色和深色样式间切换。
- Mermaid 渲染配置和缓存键加入主题；切换主题时清理缓存并重绘图表。
- HTML 导出继续使用固定浅色样式，不读取界面主题。

## 3. 最近文件

- 新增 `recent-files.js`，封装 IndexedDB 数据库、最多 12 条排序、句柄或关联地址去重和删除逻辑。
- 句柄来源记录文件句柄；双击关联来源记录经校验的 `file://` 地址，再次打开时读取最新内容但保持不可直接保存状态。
- 侧栏增加仅在可用且有记录时显示的“最近”菜单，使用浮层列表而非占用目录高度。
- 点击记录时在用户手势中申请读取权限；成功后按读写权限恢复 linked 或 unlinked 状态，失效文件自动移除。
- 增加纯逻辑测试，覆盖排序、上限、元数据和错误处理。

## 4. Mermaid 图表工具

- 成功渲染的图表增加紧凑操作栏：缩小、放大、复位、下载 SVG、下载 PNG。
- 缩放范围 0.5–3，改变 SVG 实际占位尺寸，保持横向滚动区域准确；重新渲染时回到 1 倍。
- SVG 下载从净化后的当前图表生成；PNG 使用 2 倍栅格化，并限制最大边长 8192px、最大像素数 32MP。
- 导出 HTML 时移除操作栏和缩放状态，只保留原始净化 SVG。
- 将尺寸计算和文件命名提取为纯函数并增加测试。

## 5. 侧栏与文档摘要

- 将侧栏文档操作分为打开入口、编辑操作和显示设置；“新建文档”“导出 HTML”收进互斥的更多菜单。
- 将字号循环按钮改为小 / 中 / 大分段控件，保持现有本地存储迁移和 Mermaid 重绘行为。
- 取消四格统计卡片，把标题数并入目录标题，底部摘要显示字数、预计阅读时间及编辑模式行数。
- 新增纯逻辑统计模块，排除图片载荷、代码、Mermaid、链接地址和 Markdown 标记；增加混合文本、空文档和大体积图片测试。
- 统计改为内容变化驱动，移除每两秒重复扫描；最近菜单与更多菜单互斥并支持点击外部及 Escape 关闭。

## 6. 集成与交付

- 将版本更新为 1.7.0，同步更新 README、项目指南、发行说明、打包与结构校验。
- 扩展示例文档，加入任务列表和脚注，但保持默认预览优先。
- 运行单元测试、发行包校验和浏览器回归，覆盖两种主题、最近/更多菜单、字号分段控件、文档摘要、Markdown 扩展、图表工具及窄屏布局。
- 完成发布前代码审查；本阶段生成试用包，不自动提交、推送或创建 Release，待用户验收后发布。
