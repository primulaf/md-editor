# v1.8.0 导出、代码块与数学公式 Spec

日期：2026-08-11

状态：已实现并验收

## 背景

v1.7.0 已形成以阅读为主、按需编辑的离线 Markdown 工作流，但仍有三处能力缺口：预览内容不能单独打印为 PDF，代码块缺少复用入口，行内与块级数学公式尚未渲染。

## 目标

1. 将当前预览以适合纸张的版式交给 Chrome 打印，并支持用户选择“另存为 PDF”。
2. 为普通代码块提供一键复制和按语言下载源码文件的能力。
3. 使用本地 KaTeX 渲染行内与块级公式，并保持预览、HTML 导出和 PDF 输出一致。
4. 所有新增能力继续完全离线，不扩大扩展权限，不加载 CDN 或远程字体。

## 1. 打印 / 导出 PDF

### 交互

- “更多文档操作”菜单新增“打印 / 导出 PDF”。
- 点击后先完成 Mermaid 渲染和公式排版，再生成独立打印文档并打开 Chrome 打印窗口。
- 首次打印时明确提示选择 Chrome 自带的“另存为 PDF”，并说明 Windows 的“Microsoft Print to PDF”可能将文字转换为不可选择的轮廓；用户可选择不再提示。
- 状态栏明确提示选择 Chrome“另存为 PDF”，不宣称扩展已直接生成 PDF 文件。
- `Ctrl/Cmd + P` 打印当前 Markdown 预览，而不是包含侧栏和编辑区的扩展界面。

### 输出规则

- 打印内容固定使用 GitHub 风格浅色，不受界面主题影响。
- 默认 A4、适当页边距；标题、表格、引用、代码块、图片、公式和 Mermaid 图表设置合理的分页规则。
- 宽表格、代码块和 Mermaid 图表必须适配纸张宽度，不能因预览区横向滚动策略而被截断。
- 不输出代码块工具栏、Mermaid 工具栏、状态提示或其他扩展控件。
- 图片、Mermaid SVG 和 KaTeX 字体在打印开始前完成加载。
- Mermaid 打印容器按纸张内容区计算边框盒宽度，图表不得因内边距额外挤出页面右侧。

### 非目标

- 不绕过 Chrome 打印窗口静默保存 PDF。
- 不引入基于截图的 PDF，也不引入需要手工维护中文字体子集的 PDF 生成库。
- 不提供页眉、页脚、纸张尺寸等自定义面板；这些设置继续由 Chrome 打印窗口负责。

## 2. 代码块工具

### 范围与交互

- 普通围栏代码块和缩进代码块显示紧凑工具栏；行内代码不显示。
- 工具栏左侧显示规范化语言名，右侧提供“复制”和“下载”。
- Mermaid 代码围栏继续使用既有图表工具，不重复显示代码块工具栏。
- 复制成功或下载完成后提供短暂的局部反馈和状态栏提示；失败时说明原因。
- 工具栏始终位于代码内容上方，不覆盖第一行代码；键盘焦点清晰，触屏环境保持可见。

### 下载规则

- 下载内容必须是代码文本，而不是语法高亮后的 HTML。
- 文件名格式为 `<文档名>-code-<序号>.<扩展名>`，序号按当前文档中的普通代码块顺序生成。
- 常见语言和别名映射到对应扩展名，例如 Python → `.py`、JavaScript → `.js`、JSON → `.json`、Shell → `.sh`。
- 未标注或未知语言统一下载为 `.txt`，不能根据代码内容猜测语言。
- 不在 DOM 属性中重复保存大段源码，避免多标签页场景增加不必要的内存占用。
- HTML 与 PDF 输出移除工具栏，但保留原始 `<pre><code>` 内容和代码高亮。

## 3. 数学公式

### 语法

- 行内公式支持 `$...$`。
- 块级公式支持 `$$...$$`。
- 反斜杠转义的美元符号保持普通文本。
- 代码围栏与行内代码中的公式分隔符不得参与解析。
- 行内美元语法采用保守边界规则，降低金额文本被误识别为公式的概率。

### 渲染与安全

- 使用锁定版本的 KaTeX 和 Markdown-it 数学插件，JS、CSS 与字体全部同步到 `lib/`。
- 使用 `htmlAndMathml` 输出，兼顾视觉排版和辅助技术。
- 配置 `trust: false`、有限的宏展开次数和尺寸上限；公式不能加载远程图片或注入自定义 HTML 属性。
- 公式错误时显示原始公式并标记错误，不得中断整篇 Markdown 渲染。
- DOMPurify 允许 KaTeX 所需的安全 HTML、SVG 和 MathML，同时继续净化用户提供的原始 HTML。
- 公式颜色跟随预览主题；HTML 和 PDF 输出固定使用浅色。

### 导出与性能

- HTML 导出继续保持单文件自包含，KaTeX CSS 和实际需要的字体以 Data URL 内嵌。
- 无公式的 HTML 导出不嵌入 KaTeX 字体，避免无意义增大文件。
- PDF 打印等待字体加载完成，保证分数线、根号和特殊符号完整。
- 文档统计排除数学公式源码，避免复杂公式放大字数和预计阅读时间。
- 发行 ZIP 继续满足既有不超过 3 MB 的体积门槛；记录加入 KaTeX 后的实际增量。

## 4. 默认文档与文档更新

- 首次打开示例增加一条行内公式和一条块级公式。
- 功能表补充 PDF、代码块工具和数学公式。
- README 更新安装、功能、快捷键、公式语法和技术栈。
- 新增 `docs/releases/v1.8.0.md`，版本号在 `package.json` 与 `manifest.json` 中保持一致。

## 5. 验收标准

- 长文档可从菜单或 `Ctrl/Cmd + P` 打开打印窗口，打印预览中没有扩展 UI，宽内容不被横向截断。
- 代码块可复制完整 Unicode 文本和尾部换行；至少覆盖无语言、Python、JSON、Shell 与未知语言下载。
- `$E=mc^2$` 与 `$$\int_0^1 x^2\,dx$$` 正确渲染；金额、转义美元符号和代码中的美元符号保持原样。
- 错误公式不影响其他 Markdown、Mermaid、目录、同步滚动和保存操作。
- 含公式的 HTML 文件断网后仍可独立显示；不含公式的 HTML 不携带 KaTeX 字体载荷。
- 浅色、深色、三档字号、编辑/阅读模式和多标签页场景无明显回归。
- `npm test`、`npm run package` 和发行包结构校验全部通过。
