# v1.6.2 编辑区图片与滚动操作优化 Spec

## 目标

- 内嵌图片的 DataURL 不再直接占据编辑区的大段篇幅。
- 目录跳转和编辑、预览同步滚动不再被超长图片编码干扰。
- 保存后的 Markdown 继续包含标准 DataURL，不引入外部资源目录或私有文件格式。
- 编辑区和预览区滚动条更容易发现、点击和拖动。
- 分栏拖拽区域不再覆盖编辑区滚动条。

## 图片短引用

编辑区使用短引用表示内嵌图片：

```markdown
![示例图片](md-image:1)
```

真实 DataURL 存放在当前标签页独立的图片资源表中。以下操作使用完整 DataURL：

- Markdown 预览
- 保存和另存为 Markdown
- HTML 导出
- 从编辑区复制包含完整图片引用的文本

短引用只存在于工具内部的编辑状态，不会写入用户文件。

## 兼容与生命周期

- 粘贴或拖入图片时直接生成短引用。
- 打开包含 DataURL 图片的旧文档时自动提取图片数据并替换为短引用。
- 在编辑区粘贴包含 DataURL 图片的 Markdown 文本时自动收起编码。
- 图片资源表使用 `sessionStorage` 按标签页持久化，刷新页面后继续可用。
- 新建或打开其他文档时清空上一文档的图片资源表。
- 缺少短引用对应的数据时禁止保存或导出，避免写出损坏文档。
- 修改状态以编辑区短引用文本为基准；源文件冲突检测以展开后的标准 Markdown 为基准。

## 滚动与分栏

- 编辑区和预览区使用 12px 滚动轨道及更清晰的悬停状态。
- 分栏手柄宽度由 4px 增加为 6px。
- 手柄扩展命中区域只能进入预览侧，不得覆盖编辑区滚动条。
- 鼠标拖拽继续限制编辑区比例在 20% 到 80%。
- 手柄支持左右方向键，每次调整 5%，并暴露分隔条语义和当前比例。

## 非目标

- 不引入 CodeMirror、Monaco 等完整代码编辑器。
- 不把图片拆分为磁盘上的独立文件。
- 不改变用户保存后的 Markdown 格式。
- 不压缩或重新编码图片内容。

## 验收标准

- 粘贴图片后编辑区不出现 Base64 长串，只出现短引用。
- 预览区立即显示图片，保存后的 Markdown 包含原始 DataURL。
- 打开旧的 DataURL 图片文档后自动显示短引用，未编辑时保持非脏状态。
- 复制短引用所在的完整图片语法时，剪贴板获得可移植的 DataURL 语法。
- 多张相同图片复用同一份资源数据。
- 刷新页面后图片预览和保存能力保持正常。
- 目录跳转和同步滚动不再受图片编码长度影响。
- 编辑区滚动条可从靠近分栏的位置稳定拖动，不触发列宽调整。
- 鼠标和键盘都可以调整分栏比例。
